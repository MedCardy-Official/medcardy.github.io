# Site notes

- Structure and i18n mechanism (data-i18n attributes, translations object in script.js,
  language stored in localStorage) are modeled directly on abzumsai.github.io.
- Theme: "Clinical Blue" — navy/blue/cyan palette and Vazirmatn font, matching MedCardy's
  existing note-taking CSS system, used across the podcast site instead of the reference
  site's teal/rose/amber palette.
- The "current material" numbers in the Episodes section are placeholders — see README.md
  for how to update them once real totals are ready.
- Gallery and team photos are placeholder tiles until real images are added under
  assets/gallery/ and assets/team/ — see README.md for the exact swap.
